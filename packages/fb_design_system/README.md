# fb_design_system

Fitness Buddy's design system (A02, A44, A64): tokens (colour, type, spacing,
radii, density, elevation, motion), the "Ink & Sky" palette (TD-116), light
and dark `ThemeData` built on `material_ui`, the bundled fonts (Outfit, Inter,
Noto Sans Arabic), the Momentum brand mark, the component set and
chart-wrapper interfaces. Pure presentation: no state management, no I/O, no
domain types (the allowlist is enforced by `test/dependencies_test.dart`).

- `FbTheme.light()` / `FbTheme.dark()`: the themes. Product
  colours Material lacks (macros, over-target, success, info, the sky
  spark, the mark's soft / mid / strong shapes and the avatar's plate) are on
  `context.fbColors`; the spark container is
  `ColorScheme.secondaryContainer`. One brand palette: a second one is two
  consts and the switch in `lib/src/tokens/palette.dart`.
- Type: Outfit for the display number (tabular figures), titles and the
  wordmark (`FbType.display/headline/title/wordmark`), Inter for the rest.
- Density: `FbDensity` (`lib/src/tokens/density.dart`) holds the compact
  values (card padding 12, card gap 8, rows 44, display 40) the app uses;
  the comfortable ones sit beside them, and the one-line `_compact` switch
  flips them all.
- Brand: the Momentum mark's geometry lives once, as const SVG path strings
  in `lib/src/brand/brand_geometry.dart`, read by a small restricted parser
  (`parseFbMarkPath`). `brand/momentum-mark.svg`, `brand/momentum-mini.svg`
  (outside `lib/`, not assets) and the Android launcher, splash and
  notification VectorDrawables are verbatim copies, checked by
  `apps/mobile/test/android/brand_sync_test.dart`: edit the const, look at
  the goldens, then copy the strings. Widgets: `FbBrandMark`,
  `FbBrandLockup` (mark + "Fitness / Buddy" wordmark, a header; the app
  passes its name) and `FbBuddyAvatar`. Identity and usage rules:
  `technical-planning/design/momentum/README.md`.
- Spacing, radii, elevation and motion are consts: `FbSpace`, `FbRadius`,
  `FbElevation`, `FbMotion`. Icons are named only in `FbIcons`.
- Built-in component strings are in `lib/l10n/fb_ds_en.arb`
  (`FbLocalizations`); everything content-like is a parameter. Add
  `FbLocalizations.delegate` to the app's delegates.
- Muscle map: `FbMuscleMap` draws a front and back body with `FbBodyRegion`
  sets (main dark, secondary lighter) from the MIT outline vendored into
  `lib/src/components/muscle_map_paths.dart` (generated by
  `tools/scripts/vendor_muscle_map.py`; never edit by hand). The app maps
  its muscles to regions. Provenance: `assets/licenses/SOURCES.md`.
- Call `registerFbLicenses()` once at startup (lazy: nothing is read
  until the licence page opens).
- Fonts and their licences: `assets/fonts/SOURCES.md`; vendored artwork:
  `assets/licenses/SOURCES.md`.
- Goldens: alchemist CI variant (text drawn as blocks, real font metrics).
  `make goldens` regenerates them; review the PNGs before committing.
