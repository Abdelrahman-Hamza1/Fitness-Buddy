# Glossary

| Term | Meaning |
|---|---|
| **Adaptive targets** | Calorie targets recalculated weekly from your real intake and trend weight change, instead of only a formula (TG-030). |
| **Arabizi / Franco** | Arabic written with Latin letters and numbers, e.g. "akalt 2 ta3meya". |
| **Assumption chip** | A small tappable label on a proposal card showing something Buddy assumed ("raw weight", "1 tsp oil"). Tap to change it (AI-033). |
| **Batch** | Food cooked once and eaten over several meals or shared. It stays "open" for leftovers (DY-040). |
| **Buddy** | The in-app AI assistant (D-078). |
| **Calorie shifting** | Retired by D-090: replaced by per-weekday numbers (TG-043), each day's own number, relative to the suggestion. |
| **Direct action** | Something you tap yourself (quick-add, barcode amount, manual edit). It applies immediately, with undo (AI-048). |
| **e1RM** | Estimated one-rep max, calculated from a set's weight and reps (Epley formula) (WO-041). |
| **Estimate (~)** | A value that isn't from exact data (a reference dish portion, a photo portion, or an AI estimate). Always marked, with a range on tap (D-045). |
| **Expenditure / TDEE** | Total calories your body burns per day. Estimated by formula first, then adaptively. |
| **Fajr / Maghrib** | Dawn and sunset prayer times, which mark the start and end of the Ramadan fast. |
| **Iftar / Suhoor** | The meal that breaks the fast at sunset / the pre-dawn meal before the fast. |
| **Incomplete day** | A day you didn't fully log. Excluded from adaptive calculations (DY-004). |
| **Mifflin-St Jeor** | A standard formula for estimating resting calorie burn from sex, age, height and weight (TG-020). |
| **Pending** | A proposal not yet confirmed, or a message queued while offline. Never counts toward totals (AI-045). |
| **Personal food ("yours")** | A food you created: by chat, label scan, form, saved meal or batch. Private to you (FD-070). |
| **Phase** | A goal period (e.g. "Cut, Jan–Apr"), kept in history and shown on charts (TG-012). |
| **PPL** | Push / Pull / Legs, a training split. |
| **PR** | Personal record: your best weight, e1RM or reps for an exercise (WO-042). |
| **Proposal / proposal card** | What Buddy produces from your message: a card showing exactly what would be logged or changed, confirmed with one tap (D-079, AI-030). |
| **Quick-add chips** | Buttons above the input bar for the foods and meals you're most likely to log now (DY-030). |
| **Rebalancing** | Adjusting the remaining days' targets so the week still adds up to the weekly budget (TG-041). |
| **Reference dish** | A reviewed typical recipe and portion size for a local or mixed dish (e.g. maqluba), used when exact ingredients are unknown (FD-050). |
| **Saved meal** | A named group of items you log together ("the usual breakfast") (DY-031). |
| **Slot** | A meal section in the diary (Breakfast, Lunch… or Iftar, Suhoor in Ramadan) (DY-010). |
| **Source badge** | A small marker showing where an item's numbers come from: yours / database / reference dish / estimate (FD-010). |
| **Trend weight** | A smoothed weight that filters out day-to-day water swings. The main weight number (WB-010). |
| **Weekly budget** | Your calorie allowance for the whole week. Daily targets are derived from it (TG-040). |
| **Yield factor** | How much a food's weight changes when cooked (e.g. dry rice ≈ ×2.5) (FD-060). |
